# 🎓 Student Hub

## Overview

Student Hub is a simple frontend web application developed using HTML and CSS. It provides students with a centralized interface to access important academic information such as profile details, attendance, assignments, results, timetable, and settings.

This project is designed for educational purposes and demonstrates the fundamentals of frontend web development.

---

## Features

- Login Page
- Student Dashboard
- Student Profile
- Attendance Records
- Assignments
- Results
- Timetable
- Settings
- About Us
- Contact Form

---

## Technologies Used

- HTML5
- CSS3

## Pages

Displays attendance percentage.

### Assignments

### Results
Displays academic results.

Contains account-related options.

Provides project information and a contact form.
